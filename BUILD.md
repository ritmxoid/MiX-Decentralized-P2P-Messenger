# Инструкция по сборке, запуску и тестированию MiX

## Требования
- Node.js >= 20.19
- npm >= 10

## Установка зависимостей
```bash
npm install
```

## Запуск в режиме разработки
Запускает stateless-узел рандеву/ретрансляции (`server.ts`) и Vite dev server на порту `3000`:
```bash
npm run dev
```
После запуска откройте приложение в браузере: `http://localhost:3000`.

## Проверка типов и сборка для production
```bash
npm run lint
npm run build
```

Запуск собранного приложения:
```bash
NODE_ENV=production npm start
```

## Проверка реального P2P-взаимодействия между двумя узлами
1. Откройте приложение в первой вкладке и создайте анонимный аккаунт (например, `alice`), задайте квоту хранилища и пароль.
2. Нажмите кнопку **«Открыть второй узел»** в верхней панели приложения (откроется новая вкладка с изолированным слотом IndexedDB `?slot=node-...`).
3. Во второй вкладке создайте второй аккаунт (например, `bob`).
4. В разделе **«Контакты и поиск»** найдите `@alice` или выберите обнаруженный узел, отправьте запрос и подтвердите его.
5. Перейдите в **«Личные чаты»**:
   - Отправьте зашифрованные текстовые или голосовые сообщения (E2EE `X25519 + AES-256-GCM`).
   - Отправьте файл любого размера — файл зашифруется, разобьётся кодом Рида–Соломона (`4+2`) на 6 блоков и распределится между узлами.
   - На втором узле перейдите в **«Хранилище блоков»**, чтобы увидеть полученные зашифрованные фрагменты (нечитаемые для владельца узла), или удалите часть блоков и проверьте самовосстановление в разделе **«Состояние узла»** -> **«Проверить и восстановить блоки»**.

## Запуск модульных криптографических тестов
```bash
npx tsx --test src/modules/__tests__/protocol.test.ts
```

## Автоматическая сборка `.exe` и `.apk` через GitHub Actions
В репозитории настроен workflow `.github/workflows/release-installers.yml`, который автоматически собирает готовые установщики в облаке GitHub (без установки Android Studio и компиляторов на ваш компьютер):

1. Загрузите проект в свой репозиторий на GitHub (нажмите **Export to GitHub** / `git push`).
2. *(Опционально для `.apk`)* Если у вас есть публичный адрес ретранслятора (`wss://.../ws/p2p`), добавьте в настройках GitHub репозитория (**Settings → Secrets and variables → Actions → Variables**) переменную `VITE_DEFAULT_RELAY_URL`.
3. Также при желании задайте `VITE_GITHUB_REPO` (формат `owner/repo`), чтобы кнопки скачивания в веб-интерфейсе сразу вели на ваши релизы.
4. Откройте вкладку **Actions → Build & Release MiX Installers → Run workflow** (или создайте тег `git tag v1.0.0 && git push --tags`).
5. После завершения сборки откройте раздел **Releases** в GitHub и скачайте:
   - `MiX-Setup.exe` — установщик для Windows 10/11 (включает встроенный P2P-рандеву/ретранслятор на порту `39140` и показывает локальный Wi-Fi адрес `ws://<LAN-IP>:39140/ws/p2p` для подключения телефонов);
   - `MiX-Android.apk` — установочный APK-пакет для Android 8+.

### Примечания при первом запуске неподписанных сборок
- **Windows SmartScreen**: при запуске нового `.exe` без платной коммерческой ЭЦП Windows может показать экран защиты — нажмите **«Подробнее» → «Выполнить в любом случае»**.
- **Android APK**: при установке `.apk` напрямую (вне Google Play) разрешите установку из браузера/файлового менеджера («Установка из этого источника»). Для публикации в магазинах приложений потребуется подпись релизным keystore.
